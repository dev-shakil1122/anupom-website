# Anupom Trading Contracting & Services W.L.L

This is the main website template for **Anupom Trading Contracting & Services W.L.L**. It is a modern, responsive single-page template designed to showcase the company's services, projects, and expertise.

## Features

- **Modern UI/UX**: Clean design with a blue and white color scheme.
- **CSS Animations**: Includes a custom 3D CSS-animated building illustration in the hero section, along with smooth hover effects across the site.
- **Responsive Layout**: Fully responsive navigation and grid layouts that adapt to different screen sizes.
- **Projects Section**: Includes a project gallery with different categories (e.g., Construction, Infrastructure).
- **Vanilla Tech Stack**: Built purely with HTML, CSS, and vanilla JavaScript for maximum performance and zero dependencies.

## Project Structure

The codebase has been modularized for easier maintenance:

- `index.html`: The main HTML structure containing all the sections (Hero, About, Services, Projects, Contact, etc.).
- `style.css`: Contains all the styling, including CSS variables for theming, typography, layout, and complex animations (like the 3D building).
- `script.js`: Handles interactivity, such as mobile menu toggling, smooth scrolling, project filtering, or form handling.

## Development

To work on this project:

1. Open `index.html` in your browser to view the site.
2. Edit `style.css` to modify colors, typography, layout, or animations. The primary theme colors are defined in the `:root` block at the top of the file.
3. Edit `script.js` to add or modify interactivity.
